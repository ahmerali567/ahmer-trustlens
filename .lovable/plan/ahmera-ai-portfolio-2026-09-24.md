# AHMERA.AI Portfolio

## Goal
Build a polished, dark-first one-page consultancy portfolio using Ahmer Ali’s verified CV content, portrait, and supplied project videos.

## Experience
- Sticky minimal navigation with smooth section links and a compact mobile menu.
- High-impact opening section with positioning, measurable proof, and two clear actions.
- Four capability areas, a deployment-focused architecture strip, and research credibility.
- Filterable case studies with embedded video demonstrations matched to Medicine Scanner, surveillance/activity monitoring, face recognition, and Netwave.
- Leadership section using Ahmer’s supplied portrait, verified background, CV download, GitHub, and LinkedIn.
- Accessible project inquiry modal with client-side validation, plus direct email and external scheduling handoff.

## Visual System
- Obsidian slate base with cyan and emerald accents, restrained frosted panels, fine borders, and subtle grid/noise depth.
- Geist-style sans typography with JetBrains Mono for labels, technology tags, and metrics.
- Purposeful motion: animated status signals, count-up metrics, filtered-card transitions, and reduced-motion support.
- Fully responsive layouts with strong contrast, keyboard focus states, semantic headings, and readable mobile typography.

## Technical Details
- Implement modular React sections and reusable data-driven cards in the existing TanStack app.
- Add all visual values as semantic tokens in the global design system.
- Keep uploaded media on the project asset CDN and lazy-load videos for performance.
- Add unique home-page metadata and verify desktop/mobile rendering and interactions in the browser.
